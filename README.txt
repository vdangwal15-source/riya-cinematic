RIYA — CINEMATIC FRIENDSHIP WEBSITE

Open index.html in a modern browser or serve this folder with a local web server.

Included:
- 8 supplied Riya photos
- supplied MP4 memory video
- GSAP + ScrollTrigger animations
- Lenis smooth scrolling
- Three.js particle atmosphere
- responsive mobile/tablet layout
- 3D photo wall + lightbox
- floating navigation
- optional personal soundtrack support

PERSONAL SONG:
If you have the generated MP3, rename it to:
assets/riya-song.mp3
The website already detects it and enables the Play Story button.

For best results with the MP4 and local browser security, run a local server:
Python: python -m http.server 8000
Then open http://localhost:8000
